# RFC 0119 Ratification

This directory holds the ratification-gate artifacts for RFC 0119, the
warm-tier memory boundary proposal. The RFC text is
[`../0119-warm-tier-memory-boundary.md`](../0119-warm-tier-memory-boundary.md);
the RFC index is [`../README.md`](../README.md).

Use these files as provenance for the acceptance gate, binding constraints, and
final summary. Do not use them as a replacement for the amended RFC text or the
decision log.
