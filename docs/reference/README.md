# Reference

This directory contains canonical lookup docs for Striatum's current product
contract, vocabulary, command surfaces, workflow model, and documentation
ownership rules. Start here when you need to know what is authoritative today;
use RFCs and decision records for rationale and history.

Primary lookup surfaces:

- `spec.md` is the implementation contract for current runtime behavior.
- `cli-reference.md`, `command-authority-matrix.md`, and
  `daemon-method-tables.md` describe command and daemon surfaces.
- `ubiquitous-language.md` defines Striatum's project vocabulary.
- `workflow-catalog.md` and `workflow-types.md` describe workflow families and
  selection guidance.
- `doc-map.md`, `doc-convention.md`, and `doc-convention.yaml` define doc
  ownership and convention checks.
- `prd.md`, `roadmap.md`, and `todo.md` preserve planning and backlog context.
