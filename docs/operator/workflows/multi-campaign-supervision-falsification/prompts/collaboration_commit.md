# Task

Publish the design recommendation only after the adjudicator ledger records a
clearing verdict.

## Deliverable

Publish `DESIGN_RECOMMENDATION.md` for `MULTI_CAMPAIGN_SUPERVISION` only after
the collaboration ledger clears the gate.

## Acceptance Link

Reference the clearing ledger and preserve any accepted constraints or findings from the challenge phase.

The recommendation may say proceed to RFC/product-decision drafting, proceed
with findings, revise, or no-build.

## Output Contract

Write only the declared publication artifact. Do not weaken constraints recorded
by the adjudicator, and do not include implementation tickets, source-file touch
lists, daemon schema, route maps, UI build plans, or design-to-build readiness
claims.
