# Returning Exile Ideas
author: diverger-reviewer-2-001

Frame: returning exile. I left this domain twenty years ago and came back to find yesterday's contested operating choices treated as infrastructure.

- **Forgetting is a designed affordance.** Every campaign stage gets an expiry-bound context passport that says what the next agent must remember, what it may ignore, and what has to be reopened if stale.

- **Authority now travels as a budget.** The accepted arc grants the coordinator a spend-down envelope of starts, pauses, scaffolds, and ticket edits, with each action debiting named authority instead of borrowing from chat momentum.

- **Deferral is a public mutation.** A deferred slice becomes a first-class object with owner, expiry, contradiction handle, and re-entry condition; ordinary notes cannot demote work into background fog.

- **Done is a cross-surface ceremony.** Campaign completion waits on a proof bundle that reconciles daemon state, ticket state, artifacts, Git, docs, and verifier receipts before any roadmap row can turn green.

- **The dashboard is an attention ledger.** The primary view shows where human attention is owed, where automation is still inside its envelope, and where stop pressure is rising, not a decorative map of all activity.

- **Recovery is part of the plan, not an exception.** Every arc plan names its quarantine, requeue, resume, and abandon paths up front so a wedged run produces bounded next work instead of improvised cleanup.
