# Naive Ten-Year-Old Branch Ideas
author: diverger-author-002

Vantage frame: curious 10-year-old who has never seen software.

1. Give every RFC arc a homework folder with four pockets: plan, build, check, and skipped-for-later; the helper can move a paper only when the folder also has the proof card that says who allowed it.

2. Put every campaign on a stoplight shelf where red cards always float to the front; the helper must deal with the biggest red card before it is allowed to touch a fun green one.

3. Hand each fresh agent a lunchbox with exactly five notes: what room it is in, what card is next, what it must not touch, where proof goes, and when to call the human.

4. Turn every deferral into a named promise token with a reason, owner, wake-up date, and emptying proof; skipped work stays visible until someone removes the token on purpose.

5. Give the meta-agent stage hall passes that expire after one doorway; it may start the next workflow only with a stamped pass, and every discovered slice needs its own pass.

6. Use a receipt table with four matching slots: daemon state, Git state, docs state, and ticket state; a done sticker only fits when all four receipts name the same arc, slice, and stage.
