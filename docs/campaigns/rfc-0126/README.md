# RFC 0126 P0 Review Generation

Workflow fixture for RFC 0126 P0, covering build-owned review generation. It
records the draft, independent review, and apply summary for this implementation
slice.

- `workflow.json` defines the draft, review, and apply jobs.
- `prompts/` contains the job prompts.
- `roles/` contains the author and reviewer role definitions.
- `artifacts/` contains the published draft, review, and summary artifacts.
