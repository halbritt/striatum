# Doctor Integrity Legibility P1

Workflow fixture for the P1 doctor-integrity legibility campaign. It extends the
P0 work toward a `doctor ok=true` state by documenting follow-up integrity
classification rules and their apply-stage result.

- `workflow.json` defines the draft, review, and apply jobs.
- `prompts/` contains the job prompts.
- `roles/` contains the author and reviewer role definitions.
- `artifacts/` contains the draft and summary artifacts currently present here.
