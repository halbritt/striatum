# Doctor Integrity Legibility P0

Workflow fixture for the P0 doctor-integrity legibility campaign. It records a
draft, independent review, and apply pass for making integrity output easier to
read without suppressing genuine-loss problems.

- `workflow.json` defines the draft, review, and apply jobs.
- `prompts/` contains the job prompts.
- `roles/` contains the author and reviewer role definitions.
- `artifacts/` contains the published draft, review, and summary artifacts.
