# Campaign Fixtures

This subtree holds Striatum campaign and workflow fixtures used to exercise or
record multi-agent runs. Each campaign directory is self-contained around a
`workflow.json` plus the supporting directories it needs.

- `prompts/` directories contain job prompts.
- `roles/` directories contain lane role definitions.
- `artifacts/` directories contain produced or expected run artifacts.
- `artifacts/review/` directories contain review-only outputs when present.
