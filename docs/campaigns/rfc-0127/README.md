# RFC 0127 P0 Plain-dir Workspace

Workflow fixture for RFC 0127 P0, covering the opt-in plain-directory workspace
slice. It records the draft and review artifacts for the implementation
campaign.

- `workflow.json` defines the draft, review, and apply jobs.
- `prompts/` contains the job prompts.
- `roles/` contains the author and reviewer role definitions.
- `artifacts/` contains the draft and review artifacts currently present here.
