# Frozen Records

This directory contains historical Striatum and incubation-era material preserved
for provenance during documentation consolidation. It includes retired issue
workflow packets, old reviews, research notes, source templates, request inputs,
and RFC-era artifacts that are no longer the active documentation surface.

Status: frozen archive. Keep existing records stable except for navigation,
classification, or link-maintenance work. New active operator state belongs in
`docs/operator/`; new campaign and dogfood material belongs in `docs/campaigns/`
or `docs/dogfoods/`; whole-repo audits belong in `docs/audits/`.
