# Records

`docs/records/` holds durable historical material that should stay discoverable
without making the curated docs look current when they are not. It is the place
for frozen provenance, retired workflow packets, old request inputs, research
snapshots, and migration-era evidence.

This directory is intentionally separate from the active surfaces. `docs/operator/`
contains the current operator brief, plans, progress notes, and runnable operator
workflow material. `docs/campaigns/` and `docs/dogfoods/` contain curated campaign
and dogfood material. Whole-repo audits now belong in `docs/audits/`. Records
keeps the archival tail so those surfaces can stay concise.

Status: archival/provenance. Add material here only when preserving a historical
input or output is more important than turning it into current guidance. Do not
treat records as the live work queue unless a current operator or RFC document
explicitly points here for archaeology.
