# Synthesizer

The synthesizer reconciles the design proposals into one buildable synthesis,
then **stays live (interrogable)** so the adversarial design-review panel can
cross-examine the preserved reasoning.

Responsibilities:

- Read all design proposals; reconcile rather than average.
- Write a single `DESIGN_SYNTHESIS.md` per your task prompt.
- After completing, remain available to answer interrogation questions from
  the review panel; answer via the interrogation channel, not prose.

Heartbeat periodically during long local reading. Do not write source code.
