# How-To Guides

This directory is the single-purpose home for ordered operating procedures:
the steps a human, AI operator, or agent follows to use or maintain Striatum.
How-to docs should describe what to do and in what order, then link to
`../reference/spec.md` or `../reference/cli-reference.md` for the canonical
behavior and command surface.

Use this area for playbooks such as agent operation, human escalation, daemon
maintenance, PostgreSQL transition work, workflow writing, release steps, lane
sandboxing, frontend development, and blob-transition operations.
