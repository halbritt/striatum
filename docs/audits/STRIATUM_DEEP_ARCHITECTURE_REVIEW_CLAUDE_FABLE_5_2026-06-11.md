## E. The inverse check — what's genuinely missing (high bar)

Five things are load-bearing and absent or broken. (The 06-02 list — acceptance gate, one rescue verb — is closed.)

1. **The unattended product can kill itself on a transient DB error.** Any error from a sweep iteration — including a transient PG failure in the run-listing query — propagates out of `RunScheduler` (`pkg/recovery/scheduler.go:53-55`) and `cmd/striatumd/main.go:698-701` **cancels the entire daemon**. One PG restart = the orchestrator that exists to survive failures shuts down. Compounding it: the sweep still runs git subprocesses *inside* the lock-holding transaction (`recovery.go:2051` via `expireLeases`→`anchorWorktreeCommitStack`) — the exact convoy class #198 was fixed for, surviving one layer down. This is the highest-value fix in the repo right now.
2. **`work.heartbeat` has zero behavioral tests** (`lifecycle.go:823-866`) — the input the entire heavily-tested recovery decision tree keys off. Lease extension, session binding on heartbeat, the heartbeat event: untested. A regression here silently breaks stall classification everywhere. Same tier: `worktree.create`'s composed happy path is untested (`worktree.go:41-145` — pieces tested, composition not), and four packet-content blocks nobody asserts (`buildAdapterConstraints`/`harnessProfileView`/`buildReviewPolicy`/`artifactAuthorIdentity`, `claim.go:1345-1489`) — they dictate what every lane is told.
3. **The conformance tier registry can lie, in the direction the product cares most about.** The "supported" seat tier rests on registry booleans reconciled against fixture registration — but not against *execution*: the scheduled installed-CLI workflow runs **only agy** (`go/Makefile:71` filters to `^TestInstalledCLISeatAgyTwoTurn$`); codex's supported tier rests on an on-demand fixture no CI runs; **claude — the flagship adapter, the one #101/#121 actually wedged — has no installed-CLI fixture at all** (absent from `InstalledCLISeatFixtures` and `supportedSeats`, `seats.go:59-62`). The "tier cannot lie" guard (`seat_tier_guard_test.go`) verifies registry↔registry, not registry↔CI.
4. **The lane-isolation investment leaks its own secret.** The full lane env — including the literal `STRIATUM_MCP_TOKEN` — is passed as `tmux new-session/respawn-pane -e KEY=VAL` argv and `sudo … env -i KEY=VAL` argv (`supervisor/pty.go:74-78, 241, 274, 329-335`): transiently world-readable in `/proc/*/cmdline` by **any local user**, on the same host where #201 just hardened cross-user lane isolation. The RFC 0110/0114 read-scope ladder is climbing past a window left open at the PTY layer.
5. **RFC 0104's invariant has one unguarded door**: the escalation-resolve completion re-drive (`pkg/reads/escalation_resolve.go:156` → `maybeCompleteRun`) takes no `lockRun` and isn't under the deadlock-retry wrapper — the inverted lock order the advisory lock exists to prevent, on the newest (RFC 0118) path. The `run_lock_guard_test.go` SQL-order recorder covers claim/verdict/cancel/sweep but not this reads-side entry.

Smaller but real, same class: the daemon's `seenRequests` dedupe map grows unboundedly and is fed pre-auth (`rpc/server.go:81,285-295`); CLI calls have no default read deadline, so a wedged daemon hangs every verb (`client.go:184-186` + `main.go:192`); RFC 0111's remediation suggestions — the feature's entire point — are silently dropped on the CLI path (`client.go:218-228`, `dispatch.go:355-361`); FIFO delivery buffers packets in daemon memory and records `supervisor.packet_delivered` anyway, so a restart silently drops up to 10 "delivered" packets per pipe (`supervision_delivery.go:134-161` + `supervision_control.go:434-440`); abandoned runs accumulate forever (#246, open, already biting: 7 stuck runs adding sweep load).
